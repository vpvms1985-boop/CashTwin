# CashTwin

### Consented Financial Inclusion & Explainable AI Liquidity Engine

CashTwin is an MSME-focused financial intelligence prototype that helps businesses understand their future cash position, identify liquidity risks, and evaluate possible actions before a cash-flow crisis occurs.

## Key Features

- Excel/CSV financial record ingestion
- Data validation and review
- User consent and financial-data transparency
- Invoice and receivable tracking
- Expense and cash-outflow tracking
- CashTwin Digital Twin
- Cash-flow forecasting
- Liquidity Risk Center
- What-If scenario simulation
- Resilience options with financial impact

## Prototype Workflow

Business Data → Validation → Invoices & Expenses → Digital Twin → Cash-flow Forecast → Risk Identification → What-If Simulation → Resilience Options

## Data

The current prototype uses structured/synthetic financial records to demonstrate the workflow. The system is designed to support structured business records such as invoices, expenses, payments and bank transactions.

## Technology

- Python
- Django
- HTML/CSS/JavaScript
- SQLite
- Excel/CSV data ingestion

## Purpose

CashTwin does not make financial decisions for the business owner. Instead, it provides explainable insights and scenario analysis so the owner can make informed decisions.
